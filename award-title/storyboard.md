# Storyboard: nomination video (43 s, 3840×2160, 60 fps)

**Visual motif:** gold dust. The dust gathers into each name and comes apart again when the name leaves, so the same particles carry the whole film. A nominee is literally assembled from gold. It is the one visual element shared by every shot.

Music is 120 BPM (1 beat = 0.5 s). Every impact lands on a beat.
